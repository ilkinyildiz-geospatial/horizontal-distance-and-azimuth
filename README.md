Simple Python scripts for basic geodetic and surveying calculations, specifically designed for 2D Cartesian coordinate systems.
* **Horizontal Distance (`horizontal_length.py`):** Calculates the Euclidean distance between points[cite: 1].
* **Azimuth Calculation (`semt_hesaplayici.py`):** Computes the azimuth (semt açısı) in **grad** units based on coordinate differences[cite: 2].
* 2 boyutlu kartezyen koordinat sistemleri için temel jeodezi ve harita hesaplamaları yapan basit Python betikleri.
#### Özellikler
* **Yatay Mesafe (`horizontal_length.py`):** Noktalar arasındaki Öklid mesafesini hesaplar[cite: 1].
* **Semt Açısı Hesabı (`semt_hesaplayici.py`):** Koordinat farklarına dayanarak **grad** biriminde semt açısı hesaplaması yapar[cite: 2].
